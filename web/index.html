Click Start game to play with the bundled free (CC0) data pack — no download needed. The free pack is an early work in progress: placeholder art, one original starter mission.

Optional: play with the classic X operations 0.96 data
  1. Download X operations 0.96 — xops096.zip (about 5 MB) from the original Vector distribution. Download page / fallback. OpenXOPS engine/source downloads (1.080.zip / 1.080-src.zip) are not game data.
  2. Keep the ZIP as downloaded; do not extract it.
  3. Load it below. It layers over the free pack, adds the 58 classic missions and stays in this browser; it is not uploaded.

Multiplayer deathmatch (experimental)

The validated ZIP is remembered on this browser/device. Clearing site data or using private browsing can remove it. Forget saved ZIP deletes the saved copy.
